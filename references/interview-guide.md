# 从对标到方向的逐步问答

## 接住已有材料

对标记录包含3个账号，每个记录名称／主页、简介摘录、主要内容、2条代表作、观察到的形式、想借鉴什么和能否跟做；未看清的写待核实。

先用1—2句复述共同点和差异，再问一个最影响选择的问题。不把每个空格变成一轮必答，不要求重填已有材料。只有账号名就读取对应内置B条目；没有则请补最喜欢的一条作品或一句观察。无法打开链接时说明使用内置快照，不虚构已看过作品。

## 问题池

按已知信息选问，不机械跑完整套。每轮只问一个具体问题，足够判断就停止。

| 缺口 | 可以问 | 用于判断 |
|---|---|---|
| 喜欢什么 | 这几个对标里，你最想自己做哪条作品？ | 对实用方法、画面效果或讲解方式的偏好 |
| 真实基础 | 最近实际用AI做过哪件小事？没用过也可以说最想完成的任务。 | 真实材料，区分已做与计划 |
| 制作条件 | 第一条更愿意录自己的讲解，还是屏幕操作配文字？ | 可完成的形式；配音、剪辑能力和时间只在影响选择时继续单独问 |
| 方向纠结 | 接下来几周，更愿意反复试办公任务、图片效果、视频镜头还是小网页？ | 结合已有案例选择主方向 |
| 帮助谁 | 用一个熟悉任务举例，你想帮别人把哪一步做容易些？ | 从任务理解受众，不强迫贴一串人群标签 |
| 包装缺称呼 | 昵称里想沿用哪个称呼？ | 用本人称呼参考真实命名结构 |

不懂“工作流”“AIGC”“Vibe Coding”等词，先用course-context.md的任务和作品解释，再继续一个问题。学员反问先回答，允许回看或改方向，不把问答当测验。

## 建议怎么给

连接三类信息：本人已确认的兴趣、任务和条件 → 具体B／V条目的作品或简介依据 → 一个主方向、2—3类可先试内容、一个形式和所需材料。

例如，想做办公、不出镜、会录屏：参考V02“工具对应任务”和V09“问题对应操作”，建议用自己的录屏与结果开始。这里的录屏是学员制作建议，不宣称两条原片一定纯录屏。喜欢电影感但不会做长片，可参考V16先练一个画面／短镜头，不直接要求做连续剧。

- 已有方向：只补影响制作的缺口，不从头访谈。
- 纠结：给两个结合本人条件的选择，解释差别，允许修改。
- 想直接看方案：给建议版，保留未知和待选状态，不把猜测当事实。
- 只改某项：定向处理，不重复完整问答。
- 带互动反馈回来：按真实问题调整先试内容，不凭一条数据判账号或方向失败。
